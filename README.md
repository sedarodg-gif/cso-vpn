# CSO VPN

Appli Android VPN simple (VMess, VLESS, Trojan, Shadowsocks), faite avec Flutter.
Moteur : flutter_vless 1.1.5.

- Écran unique : protocole, identifiant, serveur, port, bouton CONNECTER.
- ENREGISTRER / PROFILS : liste des serveurs sauvegardés.
- IMPORTER DEPUIS LE PRESSE-PAPIERS : colle un lien vmess://, vless://, trojan:// ou ss://.
- PARTAGER : copie le lien du serveur.

L'APK est construit par GitHub Actions (onglet Actions, artefact « CSO-VPN-apk »).
